# SSH 批量执行工具

一款功能完善的 SSH 批量执行工具，支持图形界面(GUI)和命令行(CLI)两种操作模式。

## 功能特性

### 主机管理
- 支持手动添加、编辑、删除主机节点
- 支持 CSV/Excel 文件格式批量导入主机列表
- 支持 JSON 和 Excel 格式导出主机列表
- 支持多节点批量选择（Ctrl/Shift 键）
- 支持主机分组管理（创建、编辑、删除分组）
- 所有配置本地持久化存储
- 支持单个主机连接/断开（「连接主机」按钮）

### SSH 核心功能
- 使用 asyncssh 实现异步高并发 SSH 连接
- 支持密码认证和密钥认证两种方式
- 支持连接超时、重试次数、并发数量配置
- 实现连接池管理，优化资源占用
- 支持普通用户切换到 root 用户登录
- 支持直接以 root 用户登录
- 所有用户均支持 PTY 会话，支持交互式命令

### 批量命令执行
- 支持并行执行和串行执行两种模式
- 支持 sudo 命令执行
- 实时输出执行日志，分色显示不同类型信息
- 提供任务终止功能
- 显示每个节点的执行状态
- 支持交互式命令序列（如 parted、fdisk 等）

### SFTP 文件传输
- 支持批量文件上传和下载
- 提供传输进度显示
- 支持任务终止
- 提供传输结果汇总
- 支持目录上传（递归上传目录及内容）
- 多节点下载同名文件自动添加 IP 标识，避免覆盖

### 结果导出
- 支持执行日志导出
- 支持生成 CSV 格式执行结果报表
- 提供错误汇总报告

## 使用说明

### GUI 模式（默认）

```bash
python main.py
```

### CLI 模式

```bash
python main.py --cli -c "command" [options]
```

#### CLI 参数说明

| 参数 | 说明 | 必填 |
|------|------|------|
| `-c, --command` | 要执行的命令 | 是 |
| `-g, --group` | 主机分组名称 | 否 |
| `-s, --sudo` | 使用 sudo 执行 | 否 |
| `-t, --timeout` | 命令执行超时时间(秒) | 否 |
| `-o, --output` | 输出文件路径(.csv或.json) | 否 |

#### CLI 使用示例

```bash
# 在所有主机上执行命令
python main.py --cli -c "hostname"

# 在指定分组执行命令
python main.py --cli -c "df -h" -g "生产环境"

# 使用 sudo 执行并导出结果
python main.py --cli -c "apt update && apt upgrade -y" -s -o result.csv
```

## 界面操作指南

### 主机管理页面

1. **添加主机**：点击"添加主机"按钮，填写主机信息
2. **编辑主机**：选中主机后点击"编辑主机"按钮
3. **删除主机**：选中主机后点击"删除主机"按钮
4. **分组管理**：点击"管理分组"按钮创建/编辑/删除分组
5. **导入主机**：支持从 Excel(.xlsx) 或 CSV 文件导入，支持导入切换 root 用户配置
6. **导出主机**：支持导出为 Excel 或 JSON 格式，包含切换 root 用户配置
7. **全部连接**：点击"全部连接"按钮连接当前分组的所有主机
8. **连接/断开单主机**：选中主机后点击"连接主机"/"断开链接"按钮

#### 主机配置说明

| 字段 | 说明 | 必填 |
|------|------|------|
| 名称 | 主机显示名称 | 否（默认为主机地址） |
| 主机 | IP 地址或域名 | 是 |
| 端口 | SSH 端口 | 否（默认 22） |
| 用户名 | 登录用户名 | 是 |
| 密码 | 登录密码 | 是（除非使用密钥认证） |
| 密钥认证 | 使用密钥文件登录 | 否 |
| 切换到 root 用户 | 登录后自动切换到 root | 否 |
| root 密码 | root 用户密码 | 否（切换 root 时必填） |
| sudo 配置 | 启用 sudo 执行 | 否 |
| 分组 | 主机所属分组 | 否 |

#### Excel 导入导出格式

支持导入/导出以下列（支持中英文列名）：

| 中文列名 | 英文列名 | 说明 |
|----------|----------|------|
| 名称 | name | 主机显示名称 |
| 主机 | host | IP 地址或域名（必需） |
| 端口 | port | SSH 端口 |
| 用户名 | username | 登录用户名 |
| 密码 | password | 登录密码 |
| 认证方式 | - | 密钥或密码（导出时显示） |
| 切换root | switch_to_root | 是否切换到 root（是/否） |
| root密码 | root_password | root 用户密码 |
| 分组 | group | 主机所属分组 |

### 命令执行页面

1. **选择执行模式**：并行执行（同时执行）或串行执行（依次执行）
2. **选择节点**：在左侧节点列表中选择要执行命令的主机
3. **输入命令**：在命令输入框中输入要执行的命令
4. **选项设置**：勾选"使用sudo"以提升权限执行
5. **执行命令**：点击"执行命令"按钮
6. **查看结果**：在执行结果表格中查看每个节点的执行状态
7. **导出结果**：点击"导出结果"按钮保存执行结果

#### 交互式命令序列

支持执行交互式命令，格式如下：

```
命令1>提示符1|命令2>提示符2|命令3>提示符3
```

**使用示例**：

| 场景 | 命令格式 | 说明 |
|------|----------|------|
| parted | `parted>(parted)|print>(parted)|quit>#` | 查看磁盘分区 |
| fdisk | `fdisk /dev/sda>Command( )|p>Command( )|q>#` | 查看分区表 |
| Python | `python>>>|print("hello")|exit()>` | 执行 Python |

**语法说明**：
- 使用 `|` 分隔多个命令
- 使用 `>` 分隔命令和期望的提示符
- 命令中可以包含空格（如 `fdisk /dev/sda`）

### 文件传输页面

1. **选择传输方向**：上传或下载
2. **选择模式**：文件传输或目录传输
3. **设置路径**：填写本地路径和远程路径
4. **选择主机**：在节点列表中选择目标主机
5. **开始传输**：点击"开始传输"按钮
6. **查看进度**：在传输日志中查看传输进度

#### 注意事项

- 上传目录时，会递归上传目录下所有文件和子目录
- 下载多个节点的同名文件时，会自动添加节点 IP 标识
- 远程路径只需输入目录，文件名使用源文件名

## 配置说明

### 连接配置

在主机管理页面右侧可以配置：
- **超时时间**：SSH 连接超时时间，默认 30 秒
- **重试次数**：连接失败后的重试次数，默认 2 次
- **并发数量**：最大并发连接数，默认 10

### 用户切换配置

支持两种方式获取 root 权限：

1. **切换到 root 用户**：登录普通用户后自动执行 `su - root` 切换
   - 需要勾选"切换到 root 用户"选项
   - 需要填写 root 密码
   
2. **直接 root 登录**：直接使用 root 用户登录
   - 用户名为 root
   - 填写 root 密码

## 注意事项

1. 使用密钥认证时，请确保密钥文件路径正确且有读取权限
2. 使用 sudo 功能时，请确保用户具有 sudo 权限
3. 执行批量操作前会弹出确认对话框，可勾选"本次打开后不再提醒"
4. 所有耗时操作均在后台线程执行，不会阻塞界面
5. 交互式命令需要在 PTY 会话中执行，确保命令格式正确
6. 切换到 root 用户失败时，连接仍然保持但无法执行需要 root 权限的命令

## 常见问题

### Q1: 连接主机失败怎么办？

A: 请检查：
- 主机地址是否正确
- 端口是否正确（默认 22）
- 用户名和密码是否正确
- 网络是否可达
- 防火墙是否允许连接
- SSH 服务是否正在运行

### Q2: 切换到 root 用户失败？

A: 请检查：
- root 密码是否正确
- 当前用户是否有权限执行 `su - root`
- /etc/pam.d/su 配置是否允许切换
- SSH 连接是否支持 PTY

### Q3: 命令执行超时怎么办？

A: 在主机管理页面增加"超时时间"配置，或在 CLI 模式使用 `-t` 参数指定更长的超时时间。

### Q4: 如何提高并发执行效率？

A: 在主机管理页面增加"并发数量"配置，但请注意不要设置过大以免对目标主机造成压力。

### Q5: 如何保存执行日志？

A: 在命令执行页面点击"保存日志"按钮，选择保存路径即可。

### Q6: 交互式命令无法执行？

A: 请确保：
- 使用正确的命令格式：`命令>提示符|命令>提示符`
- 提示符与实际程序的提示符完全匹配
- 已建立 PTY 会话（连接成功后自动建立）

### Q7: 文件下载时文件名被覆盖？

A: 不会。系统会自动在文件名后添加节点 IP 标识，例如 `filename_192.168.1.10.txt`。

### Q8: 命令执行回显有乱码？

A: 这是终端颜色代码导致的，系统已自动清理 ANSI 转义序列。如果仍有乱码，请检查终端编码设置。
